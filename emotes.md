# JJS Emotes Catalog (327 entries)

Source: https://jujutsu-shenanigans.fandom.com/wiki/Emotes

Each emote is an animation slot accessible from the in-game Animation
picker (categories: Stationary, Cosmetic, Traversal, Partner, Kill,
Interactive, Limited/Exclusive). Use these names when picking a stance,
idle, or cinematic gesture for a custom move; the player must then pick
the matching emote slot in the `ANIM_USE` picker in-game (this skill
can't compute the exact `[group, index]` pair from a name -- it's a
per-player picker selection).

Descriptions are shortened from the wiki to motion + cultural reference.
